risk**, or **Not yet** (the ticket is only partly addressed; the PR uses `Refs`
and the row says what is missing).

## What changed in the docs (so the verdicts can be re-checked)

- **ADR-0002/0003/0004**: removed references to files that do not exist
  (four test files that were never written, `docs/api.md`, a "project wiki"
  spec, the `POST /v1/capabilities/{name}/invoke`
  route and a `vault execute` command), replaced them with real tests and paths,
  and added "Implementation status" sections stating what the code does. Two
  claims were wrong and are now corrected: ADR-0004's "default 5 minutes, max 1
  hour, Ed25519, audience-bound" tokens (real: HMAC-SHA256, 60 s default, no
  maximum, no audience) and "unauthenticated callers see public metadata"
  (real: a bearer token is required). ADR status fields were left as
  `proposed`; promoting them to `accepted` is the maintainer's call.
- **Broken links**: `docs/security/threat-model.md` pointed to `../SECURITY.md`
  (no such file; the policy is `.github/SECURITY.md`); the bug-report template
  pointed to `../../SECURITY.md`; CONTRIBUTING named a missing
  `core-architecture.md`. All fixed and guarded by
  `tests/test_docs_claims.py::test_relative_links_resolve`.
- **API reference**: [`docs/guides/api.md`](../../guides/api.md) now leads with
  the Go routes from `go/internal/server/router.go` (every route, its auth,
  body, response and the Go-specific behaviours), then documents the legacy
  Python routes from `python/server/app.py` as the reference for **Gap (Go)**
  items.
