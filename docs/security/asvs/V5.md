## 3. HTTP Parameter Pollution (HPP) & Duplicate Field Precedence (RGT-351)

1. **URL Query Parameters (`GET /v1/secrets`, `GET /v1/secrets/{ns}/{name}`, `POST .../revoke`, `GET /v1/audit`, `GET /v1/capabilities/list`):**
   - Go handlers read query parameters through `r.URL.Query().Get(key)`, `queryDefault`, `queryInt`, and `querySubject` (`go/internal/server/handlers/handlers.go:218-235, 365-390, 496-523, 740, 1064-1069` and `identity.go:135-140`).
   - Standard-library `net/url.Values.Get` and `v[0]` slice indexing deterministically return the **first** value associated with a key when duplicate query parameters are supplied (e.g., `?namespace=ns-first&namespace=ns-second` evaluates `namespace="ns-first"`, and `?limit=1&limit=50` evaluates `limit=1`).
   - Verified by `TestASVS_V5_HTTPDuplicateQueryParameterPrecedence` in `go/internal/asvs/asvs_v5_test.go`.
   - *Gateway note:* While Python's Starlette/FastAPI selected the *last* duplicate query parameter, the Python line is end-of-life (2026-11-26) and the transitional cutover gateway (`go/internal/gateway`) is retired at `python/` removal (batch GZ). Within the Go line, first-parameter precedence is uniform across all routes.
2. **JSON Request Bodies (`POST /v1/*`):**
   - `decodeJSON` (`go/internal/server/handlers/handlers.go:138-171`) decodes into fixed structs with `dec.DisallowUnknownFields()` and verifies `dec.Token() == io.EOF` after the first object, rejecting concatenated JSON objects (`{"name":"a","value":"1"}{"name":"b","value":"2"}`) with HTTP 400.

## 4. Memory Safety, `unsafe`, and Subprocess Allowlists (RGT-371, RGT-374, RGT-375)

The automated AST guard test `TestASVS_V5_SourceScanNoShellExecAndAllowlistedImports` in `go/internal/asvs/asvs_v5_test.go` walks every `.go` file under `go/` on every `go test` run and enforces:

1. **Zero First-Party Cgo & Release `CGO_ENABLED=0` (RGT-374):**
   - No first-party `.go` file in `go/` may import `"C"`.
   - SQLite uses the pure-Go `modernc.org/sqlite` driver (`go/internal/store/store.go:47`), and release binaries are built with `CGO_ENABLED=0` (`go/.goreleaser.yaml:14`).
   - *Residual risk:* When built with default `CGO_ENABLED=1` (e.g., standard `go test` on Linux/macOS), the Go standard library links `runtime/cgo` for `net` and `os/user`.
2. **First-Party `"unsafe"` Allowlist & Third-Party Residual Risk (RGT-374):**
   - Within first-party `go/`, only `go/internal/providers/dpapi_windows.go` (`//go:build windows`, line `7`) may import `"unsafe"`.
   - It uses `unsafe.Slice` and `unsafe.Pointer` solely to marshal/unmarshal the Win32 `windows.DataBlob` struct for `CryptProtectData` / `CryptUnprotectData`, enforces `maxBlob = 1 << 30` before the syscall, copies the output into a Go-managed `[]byte`, zeroes the OS buffer via `clear(view)`, and frees it with `windows.LocalFree` in a `defer` block (`dpapi_windows.go:22-43`).
   - *Residual risk:* Third-party dependencies in the Go module graph (`modernc.org/sqlite`, `modernc.org/libc`, `modernc.org/memory`, `github.com/godbus/dbus/v5`, and `golang.org/x/sys`) import `unsafe` for transpiled C memory management and OS syscalls.
3. **`"os/exec"` Allowlist & No Shell Invocation (RGT-359, RGT-371):**
   - Only `go/internal/providers/exec.go` and `go/internal/providers/tpm.go` may import `"os/exec"` in production code.
   - Every invocation goes through `exec.CommandContext(ctx, name, args...)` with an explicit argv slice, a 60-second timeout (`commandTimeout` at `exec.go:15`), and `cmd.Stderr = nil` (`exec.go:32-56`).
   - No `.go` file in `go/` (including tests) may pass a shell binary (`sh`, `bash`, `zsh`, `cmd`, `cmd.exe`, `powershell`, `pwsh`) with `-c` / `/c` / `-Command`.
   - Provider errors use `describeRunError` (`exec.go:59-72`), which reports only the exit status code or error class and never echoes tool `stdout` or `stderr`.
4. **Constant Format Strings (RGT-375) & Parameterized SQL (RGT-367, RGT-368):**
   - `go vet ./...` runs the standard `printf` analyzer across all packages and tests, and `TestASVS_V5_SourceScanNoShellExecAndAllowlistedImports` AST-checks `.Printf`, `.Sprintf`, `.Errorf`, `.Fprintf`, `.Appendf`, `.Sscanf`, `.Fscanf`, `.Scanf`, `.Fatalf`, `.Panicf`, `.Logf`, `.Skipf`, `.logf`, and internal error constructors across all `.go` files in `go/` (production and `_test.go`) to ensure the format string argument is a compile-time constant string expression.
   - Code review of `go/internal/store` confirms SQL identifiers and clauses are never built from user input, and the AST guard verifies `fmt.Sprintf` is never passed to `Exec*` / `Query*` in production code.
