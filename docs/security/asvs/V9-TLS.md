## 3. Honest gaps and notes

- **Outbound `http://`** (webhooks, actions): follow-up filed; not changed here (files owned by other batches).
- **Behind a proxy**, the per-source auth-failure limiter sees the proxy's address (`handlers.ClientIP` uses `RemoteAddr`; forwarded headers are deliberately not trusted). Documented in the guide; rate-limit at the proxy.
- **Docs that over-claim TLS** outside this PR's files: `docs/governance/THREAT_INVENTORY.md` ("Implemented - TLS 1.2+ enforcement") and `docs/governance/CONTROLS_INVENTORY.md` describe controls that did not exist before this batch. They belong to the governance truth-up (B9a) and `docs/architecture/logging-policy.md` to H3; this batch makes the TLS statements true for the opt-in/non-loopback case but they should still be reworded to say "loopback plain HTTP by default".
- **Windows key ACL** is operator-enforced (see RGT-456). The Windows CI leg runs the tests that apply (`t.Skip` on POSIX-mode checks and SIGHUP).
- **Post-quantum group** `X25519MLKEM768` is offered first; a peer that does not support it falls back to X25519 transparently.
